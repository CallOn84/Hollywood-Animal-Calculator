## About The Project

[![Hollywood Animal Calculator screenshot][product-screenshot]](https://callon84.github.io/Hollywood-Animal-Calculator/)

Hollywood Animal Calculator is a fan-made web tool for players of [Hollywood Animal](https://weappy-studio.com/hollywood-animal/). In **Quick Mode** you pick the genres and story elements of a script, and the tool shows how well they work together before you spend any in-game money.

For every script you get:

* **Script compatibility**, from 1 to 5. A score of 3 is neutral: above it your tags help each other; below it, they get in each other's way.
* **Score modifier**, the percentage by which that fit raises or lowers the script's base quality.
* **Art appeal** and **Commercial appeal**, the points your tags add to each side.
* **Leans towards**, which side is stronger.
* The **weakest and strongest pairs** of tags in your script, so you can see what to swap.

This is a fan-made tool and is not affiliated with the game's developers.

## Usage

Quick Mode needs at least one genre, a setting and a protagonist. Everything else is optional.

### 1. Pick your genres

Search for a genre, or choose one from the list. Use **Add genre** to add more, then set each share with the slider, by typing a percentage into the box, or with the small up and down buttons.

![Searching for a genre, adding a second one and setting the percentages][usage-genres]

### 2. Add the story elements

Choose a setting and a protagonist, then optionally an antagonist, a finale, supporting characters and themes or events.

![Choosing the setting, protagonist, antagonist, finale, a supporting character and a theme][usage-story]

### 3. Use the quick tag search

Not sure where a tag belongs? Type its name in **Quick tag search** and pick it. It goes straight into the right field for you, and the list shows what kind of tag each match is.

![Searching for tags and watching them fill the right fields][usage-search]

### 4. Calculate

Press **Calculate** and the page scrolls to your results. After that, the results update as you change your choices. **Reset all** clears everything and starts again.

![Pressing Calculate and scrolling to the results][usage-calculate]
